# Domain Docs

## Before exploring

Read these files when they exist:

- `CONTEXT.md` at the repository root.
- `docs/adr/` decisions relevant to the work.

If they do not exist, proceed without creating them automatically.

## Vocabulary

Use terms defined in `CONTEXT.md` when naming domain concepts. If a required
concept is missing, treat that as a signal for domain-modeling work.

## ADR conflicts

If a change conflicts with an ADR, surface the conflict explicitly instead of
silently overriding the decision.
