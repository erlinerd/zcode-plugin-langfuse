# Code of Conduct

## Our standard

Contributors are expected to:

- be respectful, inclusive, and constructive;
- focus feedback on the work rather than the person;
- assume good intent while addressing impact;
- protect credentials, prompts, transcripts, and other private data;
- accept correction and revise work when new evidence appears.

Unacceptable behavior includes harassment, discrimination, personal attacks,
publication of private information, credential disclosure, and deliberate
attempts to disrupt the project.

## Enforcement

Project maintainers may edit or remove comments, reject contributions, or
restrict participation when this code is violated. Reports should be made
privately through the security or maintainer contact channel provided by the
hosting platform. Do not include secrets or private transcripts in a report.

This code applies to project spaces and public spaces where an individual is
representing the project.
